# data

- `grid_2d_data.mat`, `grid_2d_hires.mat`: entropic-bottleneck grids and optima
- `rkhs_2d_data.mat`: nine-well 20 × 20 network, potential and optimized biases
- `pentapeptide_T.npy`: 250-state pentapeptide transition matrix
- `pentapeptide_pcca5_crisp.dat`: five-macrostate PCCA+ assignment of the same states
- `pentapeptide_results.json`: earlier pentapeptide results (reference only)
