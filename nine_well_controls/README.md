# nine_well_controls

Reference values for the pathway overlaps on the nine-well network (SI S5.3).

- `part1_noise_ceiling.py`, `part1b_biased_noise.py`: independent unbiased and biased path samples
- `part2_random_biases.py`: random biases at the same budget
- `part3_positive_controls.py`: deliberate rerouting controls
- `part4_ess.py`: effective sample fractions (Table S5)
- `part5_random_routes.py`: landscape-blind routes
- `summarize.py` → `tables.md` (values behind Fig. S6)

`part1_counts.npz` (11 MB) is not included and is regenerated by `part1_noise_ceiling.py`.
